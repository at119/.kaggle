📌 Credit Card Fraud Detection

This project focuses on detecting fraudulent credit card transactions using machine learning techniques on highly imbalanced financial data.

🔍 Problem

Financial fraud causes billions in losses every year. The goal of this project is to build a classification model that can identify fraudulent transactions accurately while minimizing false positives.

📊 Dataset

The dataset used in this project is from Kaggle:
Credit Card Fraud Detection Dataset
(It contains anonymized transaction features and severe class imbalance.)

⚙️ Technologies Used

Python

Pandas & NumPy

Scikit-learn

Matplotlib / Seaborn

🧠 ML Approach

Data preprocessing and normalization

Handling class imbalance

Model training (Logistic Regression / Random Forest / etc.)

Evaluation using precision, recall, F1-score, ROC-AUC

📈 Results

The model successfully detected fraudulent transactions with strong recall while keeping false alarms low.
